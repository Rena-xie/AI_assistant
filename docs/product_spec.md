# AI Learning Assistant Product Specification


## Goal

Build an AI learning assistant that helps users learn AI engineering knowledge.

The assistant should support:

- AI technology learning
- Document understanding
- Knowledge retrieval
- Latest AI information tracking
- Learning progress management


## Target User

AI application engineer learner.


## Core Capabilities

Phase 1:

- Chat with AI models
- Answer AI engineering questions
- Load local knowledge documents


Phase 2:

- RAG knowledge base
- MCP tools
- Web search
- Learning plan generation


Phase 3:

- Autonomous learning workflow
- Evaluation system
- Continuous improvement


## Design Principle

The system follows Harness Engineering principles:

- Explicit context
- Automated evaluation
- Reproducible environment
- Observable behavior
