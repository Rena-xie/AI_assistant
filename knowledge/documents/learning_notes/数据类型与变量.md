# Python 数据类型与变量 —— AI 开发学习笔记

## 一、数据类型与变量

### 1. 五大基础数据类型

- **整数（int）与 浮点数（float）**：注意浮点数在计算机中的精度问题。
- **字符串（str）**：用 `' '` 或 `" "` 括起来的文本，支持转义字符 `\` 和多行字符串 `'''...'''`。
- **布尔值（bool）**：`True` / `False`，以及逻辑运算符 `and`、`or`、`not`。
- **空值（None）**：非常特殊的空值，不能理解为 `0`。
- **输入类型强制转换**：`input()` 拿到的永远是**字符串类型（str）**，如果需要做数字运算必须显式强转（如 `int()`）。

### 2. 变量与内存引用

- **变量本质**：理解"变量只是指向内存中对象的指针/标记"。
- **赋值原理**：执行 `b = a` 时，是将 `b` 指向了 `a` 当前指向的内容。

### 3. AI 开发实操场景

- **Token 消耗与成本计算**：API 调用费用通常按 Token 计算，需要用 `int` 和 `float` 计算成本。
- **大模型参数配置**：

```python
temperature = 0.7  # float：控制生成的随机性
max_tokens = 2000  # int：限制最大输出长度
stream = True      # bool：是否开启打字机流式输出
tools = None       # None：未配置任何外部 Agent 工具
```

- **Prompt 模板渲染**：使用三引号多行字符串 `'''...'''` 来编写长文本 Prompt（包含 System Prompt、Few-Shot 示例等）。

## 二、字符串和编码

### 1. 字符串的基本定义

- **定义方式**：字符串是括在单引号 `'` 或双引号 `"` 中的任意文本（例如 `'abc'`，`"xyz"`）。
- **表示符号与内容区别**：引号 `'` 或 `"` 本身只是字符串的表示方式，并不是字符串的一部分。例如，字符串 `'abc'` 实际只包含 `a`、`b`、`c` 这 3 个字符。
- **引号嵌套规则**：
    - 如果字符串内部包含单引号 `'`，外部可以直接用双引号 `"` 括起来。例如，`"I'm OK"` 包含 `I`、`'`、`m`、空格、`O`、`K` 这 6 个字符。
    - 如果字符串内部同时包含单引号 `'` 和双引号 `"`，必须使用转义字符 `\` 进行标识。

### 2. 转义字符 `\` 的应用

转义字符 `\` 用于在字符串中表示特殊的不可见字符或符号本身：

- **常用转义符**：
    - `\n`：表示换行。
    - `\t`：表示制表符。
    - `\\`：表示字符 `\` 本身。
- **示例**：
    - `'I\'m "OK"!'` 实际输出内容为 `I'm "OK"!`。
    - `'\\\n\\'` 实际会打印出两行，第一行是一个反斜杠 `\`，第二行是另一个反斜杠 `\`。

### 3. 原始字符串 `r''`

当字符串中存在大量需要转义的字符时，逐个书写 `\` 会非常繁琐且降低代码可读性：

- **作用**：在字符串的单引号/双引号前加上前缀 `r`，即可声明为**原始字符串**。
- **效果**：原始字符串内部的所有字符默认不进行任何转义。
- **对比示例**：
    - `print('\\\t\\')` 实际输出：`\` 后面加一个制表符再加一个 `\`。
    - `print(r'\\\t\\')` 实际输出：原样打印 `\\\t\\`。

### 4. 多行字符串 `'''...'''`

为了简化包含多行换行的字符串书写，避免在一行中塞入过多的 `\n`，Python 提供了多行字符串语法：

- **语法格式**：使用三个单引号 `'''...'''`（或三个双引号 `"""..."""`）包裹多行内容。
- **交互式提示符变化**：在交互式命令行中输入多行字符串时，提示符会从 `>>>` 变为 `...`。这表示可以继续输入下一行，`...` 是解释器给出的提示符，并不是代码的一部分。当输入完结束的三个单引号和括号后，回车即执行并打印。
- **多行原始字符串**：多行字符串前同样可以叠加 `r` 前缀使用。
- **示例**：

```python
print(r'''hello,\n
world''')
```

此时，多行字符串内部的 `\n` 会被当作普通字符原样打印，而不会产生换行效果。

### 5. 字符编码底层原理与转换

- **编码底层原理**：
    - **Unicode**：内存中统一的字符集编号（万国码）。
    - **UTF-8**：传输和保存时使用的可变长**字节**编码（英文 1 字节，中文通常 3 字节）。
- **`str` 与 `bytes` 的相互转换**：
    - `encode('utf-8')`：字符串 (`str`) → 字节流 (`bytes`)（用于保存到硬盘或网络发送）。
    - `decode('utf-8')`：字节流 (`bytes`) → 字符串 (`str`)（用于读取网络响应或文件）。
    - **内存中**：统一使用 **Unicode** 编码，保证多语言不乱码，处理效率高。
    - **保存或传输时**：转换为 **UTF-8** 编码，节省硬盘空间和网络带宽。
- **字符串格式化**：熟练掌握现代 Python 的 **f-string** 语法（如 `f"Hello, {name}"`）。

### 6. AI 开发实操场景

- **流式传输与 API 处理**：大模型在流式输出响应时，网络网卡吐出来的是一串串 `bytes`（字节流）。AI 工程师必须调用 `.decode('utf-8')` 将其还原成文字并实时刷在前端界面上。
- **向量数据库与文本切块（Chunking）**：在 RAG 系统中，我们需要计算文本的字节长度或字符长度来对长文档进行切分。
- **动态构建 Prompt**：

```python
user_name = "张三"
context = "这是从向量数据库搜索出来的参考资料..."
prompt = f"用户：{user_name}，请根据以下参考资料回答问题：\n{context}"
```

## 三、列表（List）与元组（Tuple）

在 AI 开发（无论是使用 PyTorch/TensorFlow 模型训练、还是用 LangChain/LlamaIndex 调用大模型 API）中，数据结构几乎全是以 `list` 和 `tuple` 为底层形态在流转。

### 1. List（列表）：动态可变的数据容器

- **语法要点**：
    - 创建与索引：`L = ['A', 'B']`，用 `L[0]` 取第一个，`L[-1]` 取倒数第一个。
    - 动态修改：`append()` 末尾添加、`insert()` 指定位置插入、`pop()` 删除末尾元素。
- **AI 应用开发场景**：
    - **大模型对话上下文**：Prompt 工程中最核心的对话历史就是一个 List。
        
    - **大模型对话历史**：在开发 ChatGPT 类聊天应用或 Agent 时，维护上下文对话就是对 `list` 的动态增删。
        
        ```python
        messages = [
            {"role": "system", "content": "你是一个AI助手"},
            {"role": "user", "content": "你好"}
        ]
        # 用户再发一条消息时，动态追加：
        messages.append({"role": "user", "content": "帮我写个Python脚本"})
        ```
        
    - **RAG（检索增强生成）中的文档块（Chunks）**：对长文档切分后，检索出来的相关段落会存放在 List 中依次传给大模型。从向量数据库中检索出来的最相关的 Top-K 个文档段落，也会装在 `list` 中传给大模型做参考。
        

### 2. Tuple（元组）：不可变的有序列表

- **语法要点**：
    - 定义方式：`t = (1, 2)`，一旦定义**不可修改**（没有 `append` / `pop` 等方法）。
    - 避坑点：定义只有 1 个元素的 tuple 时必须加逗号 `t = (1,)`，否则会被识别为括号运算符。
- **AI 应用场景**：
    - **图像/张量（Tensor）的 Shape（形状）**：在神经网络和图像处理中，数据的维度通常用 Tuple 表示，因为维度结构不允许被意外修改。
        
        ```python
        # 图像分辨率与通道数：(高度, 宽度, 通道数)
        image_shape = (1080, 1920, 3)
        ```
        
    - **多值返回（函数返回值）**：AI 函数经常需要同时返回多个结果（例如：`回复内容, 消耗Token数`），底层用的就是 Tuple 解包。
        
        ```python
        response, token_count = call_llm(prompt)
        ```
        

### 3. tuple 不可变的意义与并发安全

"**tuple 不可变有什么意义？因为 tuple 不可变，所以代码更安全。**"

在 AI 开发中，这一点尤为关键：

- **多线程与异步并发**：AI 接口调用（特别是大模型 API）大量依赖异步并发。如果数据结构是不可变的 Tuple，在多个请求之间共享数据时就**绝对不会出现数据被意外篡改的 Bug**。
- **字典的 Key**：只有不可变的对象（如 Tuple、字符串）才能作为 Python 字典（Dict）的 Key，在构建向量数据库索引或缓存（Cache）时经常用到。

`tuple` 和 `list` 非常类似，但 `tuple` **一旦初始化就不能修改**。它没有 `append()`、`insert()`、`pop()` 等方法。

#### 核心必须掌握的语法

1. **创建与避坑点**：
    - 正常定义：`point = (10, 20)`
    - **⚠️ 核心避坑点（定义单元素元组）**：如果元组只有 1 个元素，**必须加逗号** `t = (1,)`。如果写成 `t = (1)`，Python 会认为这是数学括号，把它当成整数 `1`。
2. **不可变性的底层含义（"表面可变"坑点）**：
    - 如果 `t = ('a', 'b', ['A', 'B'])`，虽然 `t` 是元组，但你修改里面的 `t[2][0] = 'X'` 是可以成功的。
    - **原理**：`tuple` 的"不变"指的是**元素的指向永远不变**（指向的列表内存地址没变），但它指向的那个列表本身的内容是可变的。

#### 🎓 AI 应用开发真实场景

- **模型/张量的形状**：在图像处理或深度学习张量（Tensor）中，矩阵的维度（如图像的 `(高度, 宽度, 通道数)`）必须用 `tuple` 表示，防止在计算过程中被意外修改。
    
    ```python
    image_shape = (1080, 1920, 3)
    ```
    
- **函数多返回值（Tuple Unpacking / 元组解包）**：AI 开发中的各种工具函数（如调用 API、请求数据库）经常同时返回多个结果，Python 底层就是用的 `tuple`。
    
    ```python
    def call_ai_model(prompt):
        # 返回 (生成的回答, 消耗的 token 数)
        return "这是回答内容", 150
    
    # 接收时直接解包
    response, token_count = call_ai_model("Hello")
    ```
    

### 4. List vs Tuple 对比表

|特性|List（列表）|Tuple（元组）|
|---|---|---|
|**可变性**|可变（Mutable）|不可变（Immutable）|
|**语法符号**|方括号 `[ ]`|圆括号 `( )`|
|**性能/安全**|稍慢，有数据被意外修改的风险|更快，更安全（线程安全/防止误操作）|
|**字典 Key 资格**|❌ 绝不能作为 Dict 的 Key|✅ 可作为 Dict 的 Key（因其不可变）|
|**AI 典型用途**|对话上下文、RAG 检索块、批量数据|图像尺寸/张量 Shape、多返回值、API 静态配置|

## 四、字典（dict）与集合（set）

以下是 dict 和 set 在如 LLM API 调用、RAG、Prompt 工程、JSON 提取中的具体落地场景。`dict` 和 `set` 是 AI 应用开发中使用频率最高的数据结构。

### 1. dict（字典）—— Key-Value 映射

- **创建与获取**：用 `{}` 或 `dict()` 创建。
- **防止 Key 不存在抛出 KeyError**（极为重要）：
    - **`'key' in d`**：返回布尔值。
    - **`d.get('key', default)`**：如果不存在返回默认值（不传默认值则返回 `None`）。
- **元素更新与删除**：
    - 更新/新增：`d['key'] = value`
    - 删除：`d.pop('key')`
- **哈希（Hash）机制与不可变对象**：
    - `dict` 的 Key 必须是**不可变对象**（如 `str`、`int`、不含可变元素的 `tuple`），不能是 `list`。
    - 特点：查找和插入极快（$O(1)$ 时间复杂度），但占用内存多。

### 2. set（集合）—— 无序不重复集合

- **创建与特性**：通过 `set([list])` 或 `{1, 2, 3}` 创建，**自动过滤重复元素**。
- **常用操作**：
    - 添加：`s.add(key)`
    - 删除：`s.remove(key)`
    - 集合运算：交集 `s1 & s2`，并集 `s1 | s2`。

### 3. AI 开发场景实战

#### 场景 1：大模型 API 请求参数与 JSON 格式解析（dict + get）

大模型的 API 输入和输出格式几乎全部基于 JSON，对应 Python 中的 `dict`。在使用模型吐出的字典数据时，必须习惯用 `.get()` 保护代码安全：

```python
# 假设是 LLM 接口返回的数据字典
llm_response = {
    "id": "chatcmpl-123",
    "choices": [
        {
            "message": {"role": "assistant", "content": "你好！有什么可以帮您？"}
        }
    ]
}

# 使用 .get() 方式安全提取，防止报 KeyError 导致程序崩塌
choices = llm_response.get("choices", [])
if choices:
    content = choices[0].get("message", {}).get("content", "")
    print(content)
```

#### 场景 2：Prompt 模版变量替换与系统上下文维护（dict）

在构建动态 Prompt 时，常用的上下文参数（例如当前用户 ID、系统设定、历史对话轮数）都是通过字典打包传入的：

```python
# 构造动态 Prompt 的上下文字典
context = {
    "user_role": "Python 初学者",
    "target_language": "中文",
    "max_length": 500
}

# 格式化 Prompt
prompt_template = "你是一位助手，正在回答一位{user_role}，请使用{target_language}回答。"
formatted_prompt = prompt_template.format(**context)
```

#### 场景 3：检索增强生成（RAG）与知识库去重（set）

在从向量数据库（Vector DB）检索网页或文档段落时，经常会检索到来自同一源文件或内容完全重复的 Chunk。此时需要用 `set` 进行高效去重或交集筛选：

```python
# 从向量库检索出的相关文档 ID 列表（可能包含重复项）
retrieved_doc_ids = ["doc_001", "doc_002", "doc_001", "doc_003", "doc_002"]

# 1. 使用 set 自动去重
unique_doc_ids = set(retrieved_doc_ids)
print(unique_doc_ids)  # {'doc_001', 'doc_002', 'doc_003'}

# 2. 权限校验：用 set 交集判断用户是否有访问权限
user_allowed_docs = {"doc_001", "doc_003", "doc_009"}
accessible_docs = unique_doc_ids & user_allowed_docs  # 取交集
```
