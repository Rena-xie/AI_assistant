

**第 1 名：datawhalechina/all-in-rag**

- 原因：RAG 是目前 AI 应用开发里**最核心、最高频**的技能之一（做知识库问答、智能客服、文档助手几乎都要用）。
- 中文、实战向、从零到完整项目，非常适合你现在的水平往上走。
- 学完后你能真正做出一个可用的 AI 应用。

**第 2 名：dair-ai/Prompt-Engineering-Guide**

- 原因：提示词工程是调用大模型做应用的基础中的基础。
- 不学这个，后面用 LangChain、做 Agent 都会很吃力。
- 内容系统，适合边学边实践。

**第 3 名：microsoft/AI-For-Beginners（继续学）**

- 你已经在学了，把神经网络基础 + Transformer + 大模型相关部分学完即可，不用全学。

**第 4 名：bojieli/ai-agent-book**

- 中文、专门讲 AI Agent 原理和工程实践，比直接啃 LangChain 源码更适合入门。

**第 5 名：langchain-ai/langchain**

- 等你把 RAG 和提示词基础打好后，再系统学这个框架，用来真正搭应用。


| 项目                                                                                                    | 说明                                  | 为什么适合你                                                                    |
| ----------------------------------------------------------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------- |
| **[microsoft/generative-ai-for-beginners](https://github.com/microsoft/generative-ai-for-beginners)** | 微软官方 21 课，专门教如何用生成式 AI 做应用          | 比 AI-For-Beginners 更贴近「应用开发」，有 Prompt、RAG、聊天机器人等实战，Python + TypeScript 都有 |

| **[openai/openai-cookbook](https://github.com/openai/openai-cookbook)**                               | OpenAI 官方示例合集                       | 学如何真正调用大模型 API、做 Embeddings、Function Calling 等，实用性强                       |
| **[Shubhamsaboo/awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)**                 | 100+ 可直接运行的 LLM 应用 / Agent / RAG 示例 | 看别人怎么写完整应用，直接 clone 跑起来改，学习效率高                                            |

1. **继续** microsoft/AI-For-Beginners（神经网络 + Transformer 基础）
2. **并行或紧接着** microsoft/generative-ai-for-beginners（更偏应用）
3. **系统学** dair-ai/Prompt-Engineering-Guide（你已收藏）
4. **重点做** datawhalechina/all-in-rag（你已收藏）→ 做出完整 RAG 项目
5. **再学** datawhalechina/hello-agents 或直接看 awesome-llm-apps 里的示例
