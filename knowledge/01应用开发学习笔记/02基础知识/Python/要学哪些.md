### 1. 核心必备（基石与工程通用语法）

- **基础语法与数据结构（第 1–7 章）**：基础数据类型、`list`/`tuple`/`dict`/`set` 操作、条件分支与循环、函数定义与参数类型（位置/关键字/可变参数）、切片、列表生成式、生成器（`yield`）与迭代器。
    
- **函数式编程与模块管理（第 8–9 章）**：高阶函数（`map`/`filter`/`sorted`）、`lambda` 匿名函数、**装饰器（Decorator，重点）**、模块导入与 `venv` 虚拟环境（16.13）。
    
- **面向对象编程体系（第 10–11 章）**：类与实例、继承与多态、`@property` 属性拦截、`__slots__` 内存优化、常见魔术方法（如 `__call__`、`__str__`、`__iter__`）。_(注：11.6 元类前期了解概念即可)_
    
- **异常处理与基础 IO（第 12–13 章、15 章）**：`try...except...finally` 异常捕捉、`with` 语句文件读写、JSON 序列化、`re` 正则表达式。
    

### 2. 高频进阶（后端、爬虫与 AI 开发必修）

- **并发与多任务（第 14 章）**：多进程（`multiprocessing`）、多线程（`threading`）、理解 Python GIL 锁对 CPU / IO 密集型任务的影响。
    
- **常用标准库与 HTTP 库（第 16–17 章）**：`datetime` 时间处理、`collections` 高级容器、`argparse` 命令行解析、`hashlib` 加密，以及第三方 **`requests`** 库。
    
- **数据库交互（第 21 章）**：SQL 基础操作，重点掌握 **SQLAlchemy**（ORM 框架映射）。
    
- **异步编程（第 23 章）**：`async`/`await` 协程语法、`asyncio` 事件循环、`aiohttp` 异步 HTTP 客户端（高并发网络请求必备）。
    

### 3. 按需了解（无需死记，用时查阅）

- **图形界面（第 18 章）**：海龟绘图（Turtle）仅适合初学者入门做趣味演示，实际开发极少用到。
    
- **电子邮件与底层网络（第 19–20 章）**：理解 TCP/UDP 和 SMTP/POP3 协议原理即可，实际业务使用现成 SDK。
    
- **传统 Web 基础（第 16.11–16.12 章、第 22 章）**：了解 HTTP 协议与 WSGI 接口原理即可。实际项目建议直接选择 FastAPI、Django 或 Flask 等现代化 Web 框架，无需深入传统的 HTML/XML 手工解析与原生模板。
