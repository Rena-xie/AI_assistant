### 一、 核心知识点与概念映射

#### 1. 编程范式的转变：面向过程 vs 面向对象

- **面向过程（Procedural）**：以“步骤”为核心，把业务拆解成一个个函数按顺序执行（`input -> function1 -> function2 -> output`）。
    
- **面向对象（OOP）**：以“对象”为核心，把数据（属性）**与**操作数据的逻辑（方法）打包封装为一个整体（类），通过对象之间的交互来解决问题。

#### 2. 类（Class）与实例（Instance）

- **类（Class）**：是抽象的蓝图/模板（例如“大语言模型客户端”）。
    
- **实例（Instance）**：是根据蓝图创建出来的具体实体（例如“配置了 Key-123 的 GPT-4o 客户端对象”）。

#### 3. OOP 三大核心特性（OOP Trinity）

1. **封装（Encapsulation）**：把属性和方法隐藏在类内部，外部只需调用公开接口，无需关心内部算法实现。
    
2. **继承（Inheritance）**：子类自动继承父类的属性和方法，避免代码重复，实现逻辑复用。
    
3. **多态（Polymorphism）**：同一操作作用于不同的子类对象上，可以产生不同的行为（实现统一调用接口）。

- **创建实例**：像调用函数一样调用类，即可生成一个具体的实例对象。

```
class Student:
```

#### 2. `__init__` 构造方法（初始化属性）

- **作用**：在创建实例时，`__init__` 方法会被**自动调用**，用于为实例绑定属性（如名称、API Key、配置参数）。
    
- **特点**：
    
    - 第一个参数必须是 **`self`**；
        
    - 创建实例时，不需要传 `self`，只需传入后面的参数。
        

Python

```
class Student:
    def __init__(self, name, score):
        # 将传入的参数绑定到实例的属性上
        self.name = name
        self.score = score

# 实例化时自动触发 __init__
bart = Student('Bart Simpson', 59)
print(bart.name)   # Bart Simpson
print(bart.score)  # 59
```

#### 3. 彻底理解 `self` 的本质

- **`self` 是什么**：`self` 代表的是**当前正在被创建或调用的那个实例对象本身**。
    
- **内存机制**：当调用 `bart.print_score()` 时，Python 在底层会自动将其转换为 `Student.print_score(bart)`，把 `bart` 作为第一个参数传给 `self`。
    

#### 4. 数据封装（数据与方法绑定）

- **概念**：直接在类的内部定义操作数据的方法（如 `print_score`），把数据（属性）和处理数据的逻辑（方法）“打包”在一起。外部调用者无需关心内部逻辑，直接调用接口即可。
    

Python

```
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    # 封装在类内部的方法
    def get_grade(self):
        if self.score >= 90:
            return 'A'
        elif self.score >= 60:
            return 'B'
        else:
            return 'C'

bart = Student('Bart Simpson', 59)
print(bart.get_grade())  # 输出 'C'，外部无需知道内部的判断逻辑
```

#### 场景 2：封装 AI Agent 的对话历史记忆模块（Conversation Buffer Memory）

```
        self.history = []  # 实例内部的状态存储

        return "\n".join([f"{msg['role']}: {msg['content']}" for msg in self.history])
```

### 一、 核心知识点与语法

掌握 Python 的私有变量/私有方法机制（双下划线 `__`）、Getter / Setter 属性访问器方法、名称修饰（Name Mangling）的底层机制，以及它们在 AI SDK 敏感密钥保护、Agent 内存数据校验与组件解耦中的关键落地应用。

#### 1. 私有属性与私有方法（双下划线 `__`）

- **语法**：在属性或方法名前加上**双下划线 `__`**（例如 `__api_key` 或 `__validate()`）。
    
- **效果**：该属性或方法将变为**私有（Private）**，在类的外部**无法直接通过 `instance.__api_key` 访问**，否则会触发 `AttributeError`。
    

Python

```
class LLMClient:
    def __init__(self, api_key: str):
        self.__api_key = api_key  # 私有属性，外部无法直接访问

client = LLMClient("sk-123456")
# print(client.__api_key)  # ❌ 报错：AttributeError: 'LLMClient' object has no attribute '__api_key'
```

#### 2. 受保护属性（单下划线 `_`）与特殊属性（双下划线包围 `__xx__`）

- **单下划线 `_name`**：表示**受保护（Protected）属性**。Python 语法**不会强制限制访问**，但按开发规范，它提示开发者：“虽然你可以访问，但请把它视为私有变量，不要在类外部直接改动”。
    
- **双下划线包围 `__init__`**：是 **Python 的特殊/魔术变量（Special Attribute）**，可以直接访问，**不要自定义**这种格式的变量名。
    

#### 3. 访问与修改私有属性：Getter 与 Setter 方法

如果不允许外部直接修改，但又需要获取或校验属性，可以通过定义公开的 **Getter** 和 **Setter** 方法：

Python

```
class UserProfile:
    def __init__(self, age: int):
        self.__age = age

    # Getter：安全获取私有属性
    def get_age(self):
        return self.__age

    # Setter：带数据校验地修改私有属性
    def set_age(self, age: int):
        if not isinstance(age, int) or age < 0 or age > 150:
            raise ValueError("非法年龄输入！")
        self.__age = age
```

#### 4. 底层机制：名称修饰（Name Mangling）

- **本质**：Python 语言并没有真正从硬件层面禁止访问私有属性。双下划线 `__api_key` 在底层被自动改名为 `_ClassName__api_key`（如 `_LLMClient__api_key`）。
    
- **验证**：虽然 `client.__api_key` 访问不到，但通过 `client._LLMClient__api_key` 依然可以强行访问。然而**极不推荐**这样做，因为不同解释器实现可能不同。

### 一、 核心知识点与语法

掌握 **继承的语法与子类覆写（Override）**、**多态的执行机制**、**Python 特有的“鸭子类型”（Duck Typing）**，以及它们在 **AI Agent 工具抽象、自定义 VectorStore/LLM 组件扩展** 中的关键落地应用。

#### 1. 继承（Inheritance）：代码复用与类型树

- **概念**：子类（Subclass）可以继承父类（Base class / Superclass）的所有公开属性和方法，无需重复编写。
    
- **语法**：定义类时在小括号中指定父类即可 `class SubClass(ParentClass):`。
    

Python

```
class Animal:
    def run(self):
        print("Animal is running...")

class Dog(Animal):  # Dog 继承自 Animal
    pass

dog = Dog()
dog.run()  # 输出: Animal is running...（直接复用父类方法）
```

#### 2. 方法覆写（Method Overriding）与 `super()` 调用

- **方法覆写**：如果子类定义了与父类同名的方法，子类的方法会**覆盖**父类的实现，从而展现出子类特有的行为。
    
- **`super()` 关键字**：在子类中通过 `super().method()` 可以显式调用父类中被覆写的方法，通常用于扩展（而不是完全替代）父类的逻辑。
    

Python

```
class Dog(Animal):
    def run(self):  # 覆写父类的 run 方法
        print("Dog is running fast!")

dog = Dog()
dog.run()  # 输出: Dog is running fast!
```

#### 3. 多态（Polymorphism）：开闭原则的核心

- **机制**：当接受一个父类类型的参数时，传入该父类的**任意子类对象**都可以正常工作。程序在运行时会自动根据传入对象的具体类型，调用该子类对应的重写方法。
    
- **开闭原则（Open-Closed Principle）**：
    
    - **对扩展开放**：增加新的子类即可扩展新功能；
        
    - **对修改关闭**：无需修改使用该父类对象的上层业务代码。
        

Python

```
def run_twice(animal: Animal):
    animal.run()
    animal.run()

run_twice(Animal())  # 调用 Animal.run
run_twice(Dog())     # 自动调用 Dog.run（多态体现）
```

#### 4. Python 的特色：鸭子类型（Duck Typing）

- **原理**：静态语言（如 Java/C++）要求多态中的传入对象必须严格继承自某个父类。而 Python 作为动态语言，遵循 **“如果它走起来像鸭子，叫起来像鸭子，那它就是鸭子”**。
    
- **效果**：只要一个类拥有特定的方法（如 `run()`），即使它**没有继承 `Animal` 父类**，也可以直接传给 `run_twice()` 运行。
    

Python

```
class Timer:  # 没有任何继承关系
    def run(self):
        print("Timer is ticking...")

run_twice(Timer())  # ✅ 成功运行！不需要继承 Animal，只要有 run() 方法即可
```

```
class CalculatorTool(BaseTool):

        # 使用 super() 调用父类构造函数进行基础属性绑定
        super().__init__(
            name="calculator",
            description="用于执行数学加减乘除计算的工具"
        )

    def run(self, expression: str) -> str:
        return f"计算结果: {eval(expression)}"

calc = CalculatorTool()
```

### 一、 核心知识点与语法

#### 1. 类型判断：`type()` vs `isinstance()`

- **`type()`**：判断对象的基本类型，返回对应的 `Type` 对象。
    
    - 适用于基础数据类型（`int`, `str`, `types.FunctionType` 等）。
        
    - **缺陷**：无法识别类的**继承树关系**。
        
- **`isinstance()`（强烈推荐）**：判断一个对象是否属于某个类，或者属于该类的**子类**。
    
    - 语法：`isinstance(obj, ClassName)` 或 `isinstance(obj, (ClassA, ClassB))`（传入元组判断是否符合其一）。
        

Python

```
class Animal: pass
class Dog(Animal): pass

d = Dog()
print(type(d) == Dog)       # True
print(type(d) == Animal)    # False (type 不考虑继承)

print(isinstance(d, Dog))   # True
print(isinstance(d, Animal))# True (isinstance 考虑继承关系，更符合面向对象逻辑)
```

#### 2. 探索对象的所有属性和方法：`dir()`

- **`dir(obj)`**：返回一个包含该对象所有属性和方法名称的**字符串列表**。
    
- **`__len__()` 魔术方法**：在 Python 中，`len("ABC")` 底层实际上就是自动调用 `"ABC".__len__()`。如果我们自定义的类也实现了 `__len__()` 方法，就可以对该类的实例直接使用 `len()`。
    

Python

```
class CustomDataset:
    def __len__(self):
        return 100

dataset = CustomDataset()
print(len(dataset))  # 输出 100
```

#### 3. 动态操作对象属性与方法（反射机制）：`hasattr` / `getattr` / `setattr`

在不知道对象具体类型的情况下，通过属性/方法名的**字符串**来动态查询、获取与设置：

- **`hasattr(obj, 'attr_name')`**：检查对象是否有该属性/方法，返回 `True`/`False`。
    
- **`getattr(obj, 'attr_name', default)`**：动态获取对象的属性或方法（可设置默认值防止报错）。
    
- **`setattr(obj, 'attr_name', value)`**：动态给对象设置属性或方法。
    

Python

```
class ModelConfig:
    def __init__(self):
        self.model = "gpt-4o"

config = ModelConfig()

# 1. 检查属性
if hasattr(config, "model"):
    # 2. 获取属性
    print(getattr(config, "model"))  # gpt-4o

# 3. 如果没有该属性，优雅地指定默认值（不会抛出 AttributeError）
print(getattr(config, "temperature", 0.7))  # 0.7

# 4. 动态添加/修改属性
setattr(config, "temperature", 0.2)
print(config.temperature)  # 0.2
```

### 一、 核心知识点与语法

#### 1. 实例属性（Instance Attributes）

- **定义**：通过实例变量（如 `self.name`）或者在类外部直接通过实例绑定（`student.age = 18`）。
    
- **作用域**：仅属于**当前特定的实例对象**，不同实例之间的实例属性在内存中相互隔离、互不影响。
    

Python

```
class Student:
    def __init__(self, name):
        self.name = name  # 实例属性

s1 = Student("Alice")
s2 = Student("Bob")
print(s1.name)  # Alice
print(s2.name)  # Bob
```

#### 2. 类属性（Class Attributes）

- **定义**：直接在 `class` 内部、但在所有方法定义**外部**定义的属性。
    
- **作用域**：**属于类本身**，所有根据该类创建的实例**共同共享**同一份类属性（在内存中只存一份）。
    
- **修改原则**：只能通过类名修改（如 `Student.species = "Homo sapiens"`）。如果通过实例修改，则会给该实例创建一个同名的“实例属性”。
    

Python

```
class Student:
    species = "Homo sapiens"  # 类属性（所有学生共享）

s1 = Student("Alice")
s2 = Student("Bob")
print(s1.species)  # Homo sapiens
print(s2.species)  # Homo sapiens
print(Student.species) # Homo sapiens
```

#### 3. 属性查找顺序与同名覆盖（查找优先级）

当通过实例对象访问属性（如 `s1.name`）时，Python 的查找顺序为：

1. **优先查找实例属性**：如果该实例身上有这个属性，直接返回；
    
2. **后退查找类属性**：如果实例身上没有，再去它的类（Class）属性中查找；
    
3. **未找到报错**：如果类属性中也没有，触发 `AttributeError`。
    

**⚠️ 陷阱与规范**：不要给实例属性和类属性起相同的名字！如果给实例绑定了一个与类属性同名的实例属性，它会屏蔽（Override）掉类属性。

Python

```
class Student:
    name = "StudentClass"  # 类属性

s = Student()
print(s.name)      # 输出 "StudentClass"（找不到实例属性，向上使用类属性）

s.name = "Alice"   # 动态给实例绑定同名实例属性
print(s.name)      # 输出 "Alice"（找到实例属性，屏蔽了类属性）
print(Student.name)# 输出 "StudentClass"（类属性本身保持不变）

del s.name         # 删除实例属性
print(s.name)      # 输出 "StudentClass"（屏蔽解除，恢复使用类属性）
```

|---|---|---|---|

### 四大核心模块深度提炼

#### 1. 封装与访问限制

- **私有化机制**：属性名前加双下划线 `__`（如 `__api_key`）会触发名称修饰（Name Mangling），外部直接访问会抛出 `AttributeError`。
    
- **数据安全校验**：不直接暴露属性，而是提供公开的 Getter（只读获取/脱敏）和 Setter（入参合法性检验）方法。
    
- **约定规范**：单下划线 `_attr` 属于开发约定的受保护属性，语法不限制访问，但开发者应自觉将其视为私有变量。
    

#### 2. 继承与多态（包含鸭子类型）

- **继承与覆写**：子类自动获得父类的属性与方法，重写同名方法可实现子类特有行为；使用 `super().method()` 可保留并扩展父类既有逻辑。
    
- **多态（Polymorphism）**：上层业务代码只针对父类（接口）编写，运行时传入任何子类均可正常协同工作。
    
- **鸭子类型（Duck Typing）**：Python 不要求严格的继承树关系。“只要走起来像鸭子，它就是鸭子”——任何对象只要实现了特定的同名方法，就能直接传入多态函数中调用。
    

#### 3. 获取对象信息（反射与运行时检视）

- **类型检测**：优先使用 `isinstance(obj, Class)` 而非 `type()`，因为 `isinstance()` 能正确识别继承链中的父类类型。
    
- **对象检视**：使用 `dir(obj)` 获取对象拥有的所有属性和魔术方法（如 `__len__`）。
    
- **动态反射**：通过字符串名称动态操作属性与方法：
    
    - `hasattr(obj, "name")`：检查是否存在。
        
    - `getattr(obj, "name", default)`：动态获取属性或方法，支持设置默认值防止崩溃。
        
    - `setattr(obj, "name", val)`：动态绑定新属性。
        

#### 4. 实例属性与类属性

- **内存与作用域**：
    
    - **实例属性**（挂载在 `self` 上）：每个实例各自独立，互不影响。
        
    - **类属性**（定义在类体中）：所有实例共享同一份内存，适合存全局配置或计数器。
        
- **查找优先级（屏蔽原则）**：访问 `obj.attr` 时，Python 先找实例属性；若不存在，再查找类属性。如果给实例赋与类属性同名的值，会创建一个新的实例属性并**屏蔽**类属性，但不会改变类属性本身。
    

### 在 AI / Agent 工程中的典型落地

1. **组件抽象（继承 & 多态）**：定义 `BaseLLM` 或 `BaseTool` 统一基类，轻松扩展 `OpenAILLM`、`ClaudeLLM` 或自定义搜索引擎工具，保证上层 Agent 调度逻辑无需改动。
    
2. **安全防护（访问限制）**：在 LLM Client 类中使用 `__api_key` 存储密钥，仅暴露 `get_masked_key()`，防止日志打印时泄漏敏感凭证。
    
3. **动态分发（反射）**：Agent 执行器接收到大模型返回的 JSON 指令（如 `"action": "search_web"`）后，利用 `hasattr` 与 `getattr` 动态查找并调用对应的 Python 工具函数。
    
4. **共享状态（类属性）**：使用类属性统计所有 Agent 实例累计消耗的全局 Token 总数或活跃线程数。
