## 一、 切片

在 AI 数据预处理（文本截断、Context Window 裁剪、数据集 Split）中，切片是极其基础且核心的序列截取工具。

### 1. 基础语法与缺省规则
基础语法结构为：`start:stop:step`（左闭右开，即包含 start，不包含 stop）。

缺省规则说明：
* `L[:3]`：从开头开始截取到索引 3 之前（获取索引 0, 1, 2）。
* `L[2:]`：从索引 2 开始截取直到末尾。
* `L[:]`：复制整个列表或字符串（浅拷贝）。

### 2. 高级用法与技巧
* 负数索引与倒数切片：`L[-1]` 代表最后一个元素；`L[-10:]` 获取序列最后 10 个元素。
* 步长 step 控制：`L[::2]` 每隔一个元素取一个；`L[::-1]` 反转列表或字符串（非常常用的 Pythonic 写法）。
* 支持的数据类型：适用于 List、Tuple 和 String。Python 中没有单独的 `substring()` 函数，所有序列截取统一使用切片。

### 3. AI 开发实操场景

#### 场景 1：大模型 Prompt 上下文窗口（Context Window）超长截断
大模型输入有 Token 限制，为了防止历史对话记录超长导致 API 报错，利用倒数切片仅保留最新 N 条对话：

```python
history_messages = [
    {"role": "user", "content": "问题1"},
    {"role": "assistant", "content": "回答1"},
    # ... 假设有 50 条历史记录 ...
    {"role": "user", "content": "问题25"},
    {"role": "assistant", "content": "回答25"}
]

# 利用倒数切片，仅保留最近 6 条（3轮对话）上下文传入大模型
max_history_turns = 6
context_to_send = history_messages[-max_history_turns:]
```

#### 场景 2：RAG 向量检索前的文本 Chunk 块重叠切分（Overlap Splitting）
在搭建 RAG 知识库时，为防止长文档被硬性切断而丢失上下文，通常使用带重叠（Overlap）的滑动窗口切片：

```python
def slide_window_split(text, chunk_size=500, overlap=100):
    """用切片实现带重叠的文本块切割"""
    chunks = []
    start = 0
    while start < len(text):
        end = start + chunk_size
        # 使用切片直接截取文本块
        chunk = text[start:end]
        chunks.append(chunk)
        # 窗口步长为 (chunk_size - overlap)
        start += (chunk_size - overlap)
    return chunks
```

#### 场景 3：机器学习数据集划分
模型训练或评估时，通过切片将标注数据按比例切割为训练集与验证集：

```python
dataset = ["data_001", "data_002", "data_003", "data_100"]

# 80% 作为训练集，20% 作为验证集
split_index = int(len(dataset) * 0.8)

train_set = dataset[:split_index]   # 取前 80%
val_set = dataset[split_index:]     # 取后 20%
```

## 二、 迭代

### 1. 核心知识点与语法
* 广义迭代原理：Python 的 `for` 循环不仅限于带下标的数组，只要是“可迭代对象”（Iterable）都可以直接用 `for` 遍历。
* 常见可迭代类型：List、Tuple、Dict、Set、Str、File 文件对象、Generator 生成器等。
* 字典（Dict）三种迭代模式：
  * 仅 Key：`for key in d:`
  * 仅 Value：`for value in d.values():`
  * Key-Value 双变量（最常用）：`for k, v in d.items():`
* 索引与元素双变量迭代：使用 `enumerate()` 替代 C 语言风格的 `range(len(L))`：
  ```python
  for index, item in enumerate(['A', 'B', 'C']):
      print(index, item)  # 输出：0 A, 1 B, 2 C
  ```
* 判断对象是否可迭代：通过 `collections.abc` 中的 `Iterable` 进行类型校验：
  ```python
  from collections.abc import Iterable

  isinstance('abc', Iterable)     # True
  isinstance([1, 2, 3], Iterable) # True
  isinstance(123, Iterable)       # False
  ```

### 2. AI 开发实操场景

#### 场景 1：大模型流式响应逐 Token 接收与展示
开启 `stream=True` 时，API 返回的是可迭代对象，通过 `for` 循环遍历实时接收 Token：

```python
    full_content += token
```

批量调用 Embedding 模型时，结合 `enumerate()` 与步长切片打印批次编号：

## 三、 列表生成式

### 1. 核心知识点与语法
列表生成式提供了一行代码构建列表的极简写法，替代复杂的 `for` 循环与 `append()` 操作。

* 基础语法结构：`[expression for item in iterable]`
  ```python
  # 传统写法
  L = []
  for x in range(1, 11):
      L.append(x * x)

  # 列表生成式写法
  L = [x * x for x in range(1, 11)]  # [1, 4, 9, 16, ..., 100]
  ```
* 条件筛选（仅 `if` 过滤）：放置在 `for` 循环之后，用于过滤元素：
  ```python
  [x * x for x in range(1, 11) if x % 2 == 0]  # [4, 16, 36, 64, 100]
  ```
* 三元表达式（`if-else` 分支转换）：放置在 `for` 循环之前，进行计算分支选择：
  ```python
  [x if x % 2 == 0 else -x for x in range(1, 11)]
  ```
* 多重循环与双变量解包：
  ```python
  # 双重循环
  [m + n for m in 'ABC' for n in 'XYZ']  # ['AX', 'AY', 'AZ', 'BX', ...]

  # 字典解包
  d = {'x': 'A', 'y': 'B', 'z': 'C'}
  [k + '=' + v for k, v in d.items()]  # ['x=A', 'y=B', 'z=C']
  ```

## 四、 生成器（Generator）

### 1. 核心知识点与语法
* 为什么需要生成器（内存机制）：列表生成式会将所有元素一次性载入内存；而生成器保存的是算法，只有在需要时才实时计算下一个元素（延迟计算 / 惰性求值），极大节省内存空间。
* 创建方式一：生成器表达式（Generator Expression），将列表生成式的 `[]` 改为 `()`：
  ```python
  g = (x * x for x in range(10))
  ```
* 创建方式二：`yield` 关键字定义函数生成器：
  ```python
  def fib(max_count):
      n, a, b = 0, 0, 1
      while n < max_count:
          yield b  # 每次执行到 yield 暂停并返回结果，下一次从暂停处继续
          a, b = b, a + b
          n = n + 1
      return 'done'
  ```
* 调用与遍历：推荐直接使用 `for` 循环遍历（会自动处理 StopIteration）；也可以通过 `next(g)` 手动驱动。

### 2. AI 开发实操场景

#### 场景 1：大模型流式打字机响应（LLM Streaming Protocol / SSE）
结合 `yield` 配合 HTTP 服务实现 Token 逐字推送：

```python
def stream_llm_response(prompt: str):
    """模拟大模型 API 的流式生成器"""
    response_tokens = ["你好！", "我是", "一个", " AI", " 助手", "。"]
    for token in response_tokens:
        import time; time.sleep(0.1)
        yield token  # 逐字 yield 给上层 HTTP 连接

# 客户端实时消费
for chunk in stream_llm_response("介绍你自己"):
    print(chunk, end="", flush=True)
```

#### 场景 2：海量 RAG 知识库/训练数据集的分批加载
逐行/逐批读取 GB 级海量文件，防止内存溢出（OOM）：

```python
def load_dataset_in_batches(file_path, batch_size=1000):
    """用生成器逐批读取海量数据，避免 OOM"""
    with open(file_path, 'r', encoding='utf-8') as f:
        batch = []
        for line in f:
            batch.append(line.strip())
            if len(batch) == batch_size:
                yield batch  # 满一批就 yield，并清空批次内存
                batch = []
        if batch:
            yield batch

# 处理百万行文本时内存占用保持极低
for batch in load_dataset_in_batches("huge_corpus.txt"):
    process_and_embed(batch)
```

## 五、 迭代器（Iterator）

### 1. 核心概念辨析
* 可迭代对象（Iterable）：可以作用于 `for` 循环的对象（如 `list`、`tuple`、`dict`、`str`、`generator`）。
* 迭代器（Iterator）：可以作用于 `next()` 函数并不断返回下一个值的对象。表示一个单向惰性数据流。`generator` 属于 `Iterator`，但 `list`、`dict`、`str` 本身不是 `Iterator`。

| 类型 | 是否可用于 `for` 循环 (Iterable) | 是否可用于 `next()` (Iterator) | 内存占用特点 |
| :-- | :-- | :-- | :-- |
| `list` / `str` / `dict` | 是 | 否 | 静态占用固定内存（预先载入全量） |
| 生成器 (`Generator`) | 是 | 是 | 极低（按需惰性计算） |
| `iter(list)` | 是 | 是 | 极低（转为动态指针数据流） |

* `iter()` 函数：将 `Iterable` 转为 `Iterator` 指针（例如 `it = iter([1, 2, 3])`）。
* `for` 循环的底层本质：底层等价于先调用 `it = iter(obj)`，而后在 `while True` 循环中调用 `next(it)` 并捕获 `StopIteration` 异常结束。

```python
# for 循环的 Python 底层实现等价代码
it = iter([1, 2, 3])
while True:
    try:
        x = next(it)
    except StopIteration:
        break
```

### 2. AI 开发实操场景

#### 场景 1：PyTorch / TensorFlow 自定义数据加载器（Dataset & DataLoader）
在深度学习中，`DataLoader` 返回一个 `Iterator`，训练时按批次惰性加载数据，避免全量载入爆内存：

```python
from torch.utils.data import DataLoader

train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# 训练循环中隐式转换为 Iterator 进行按批次读取
for batch_x, batch_y in train_loader:
    outputs = model(batch_x)
```

#### 场景 2：流式 Token 流的手动消费与安全校验
对 API 返回的 Token 流进行手动精准控制（如检验前 N 个 Token 是否包含违规内容）：

```python
stream_iterator = iter(llm_client.stream_generate(prompt))

# 手动提取前两个 Token 进行安全校验
first_token = next(stream_iterator)
second_token = next(stream_iterator)

if is_safe(first_token + second_token):
    # 校验通过后，继续遍历消费剩余数据流
    for remaining_token in stream_iterator:
        process(remaining_token)
```

### 3. 阶段性自测 Check List
* **能否准确说出 Iterable 与 Iterator 的区别？**
  * 答：Iterable 是指可作用于 `for` 循环的对象；Iterator 是指可作用于 `next()` 的惰性数据流对象。
* **为什么 Python 的 list、dict 是 Iterable，但设计成不是 Iterator？**
  * 答：因为 Iterator 是有状态的单向数据流，被消费后无法复用；而 `list` 需要支持多次索引和重复遍历。
* **如何判断一个对象是否是 Iterator？**
  * 答：使用 `from collections.abc import Iterator; isinstance(obj, Iterator)`。
* **理解 Python `for` 循环在底层的运行机制**：通过 `iter()` 获取迭代器，持续调用 `next()` 并捕获 `StopIteration` 退出。

## 六、 总结：高级特性全篇演进逻辑与选型指南

### 1. 全篇知识点联系与演进主线
Python 的 5 大高级特性并非孤立存在，而是沿着“代码简洁”与“内存优化”两条主线递进：

* 主线 1（数据提取与遍历）：切片 (Slicing) -> 迭代 (Iteration)
* 主线 2（数据生成与内存优化）：列表生成式 (List Comprehension) -> 生成器 (Generator) -> 迭代器 (Iterator)

1. 切片：解决指定范围连续数据的快速截取。
2. 迭代：将“遍历”操作从有索引的容器抽象到任意 Iterable 对象。
3. 列表生成式：结合迭代与条件过滤，单行优雅构建 List（空间换时间）。
4. 生成器：将 `[]` 改为 `()` 或使用 `yield`，改为实时按需计算（时间换空间）。
5. 迭代器：对生成器与数据流进行底层抽象，揭示 `iter() + next() + StopIteration` 机制。

### 2. 核心特性对比一览表

| 高级特性 | 核心作用 | 典型语法 | 内存开销 | 核心优势 | 真实 AI / 数据工程应用场景 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| **切片 (Slicing)** | 截取序列的指定子集 | `L[start:stop:step]` | 创建新对象，占用对应切片内存 | 简洁高效，替代循环截取 | Prompt 上下文截断、数据集 Split |
| **迭代 (Iteration)** | 遍历任意可迭代对象 | `for x in obj:` / `enumerate()` | 取决于被遍历的对象 | 语法糖抽象，无需关心结构类型 | 遍历流式 Response、逐 Batch 处理 |
| **列表生成式** | 单行构建全新列表 | `[expr for x in iter if cond]` | 高（一次性载入内存） | 代码极度 Pythonic，执行快 | 文档数据清洗、Prompt 结构化转换 |
| **生成器 (Generator)** | 按需惰性生成元素 | `(expr for x in iter)` / `yield` | 极低（仅保留当前元素） | 解决海量数据/无限序列内存爆满 | LLM 流式打字机响应、海量数据集 Batch 加载 |
| **迭代器 (Iterator)** | 抽象数据流指针 | `iter(obj)` / `next(it)` | 极低（单向惰性指针） | 表示无限数据流，提供统一消费接口 | PyTorch DataLoader 加载、Agent 状态控制 |

### 3. 概念包含关系图

```text
可迭代对象 (Iterable) 
  ├── 基础数据容器 (如 List, Dict, Str) [占用全量内存, 不可用 next()]
  │     └── (通过 iter() 转换为指针) ──> 迭代器 (Iterator)
  └── 迭代器 (Iterator) [惰性计算数据流, 可用 next()]
        └── (特殊实现语法) ──────────> 生成器 (Generator) [用 yield 或 () 定义]
```

### 4. 实际开发场景选型指南
* 需要截取连续区间数据：首选 **切片**。
* 数据量较小（百/千级）且后续需要频繁随机访问与重复遍历：首选 **列表生成式**。
* 数据量巨大（GB 级文本/海量文件）无法一次性存入内存：必须使用 **生成器表达式** 或 **`yield` 生成器函数**。
* 开发 Web 服务的 AI 流式打字机响应：必须使用 **`yield` 生成器**。
* 需要手动精准操控消费进度（如先校验前 N 个 Token 再决定是否放行）：使用 `iter()` 转为 **Iterator** 配合 `next()` 控制。
